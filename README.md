# Bring Your Own AI — Site

Public website for [Bring Your Own AI](https://apps.apple.com), an iOS chat client
for OpenAI, Anthropic, DeepSeek, Groq, OpenRouter, Ollama, Apple Intelligence,
and any OpenAI-compatible endpoint.

Hosted via GitHub Pages at:
**https://fredfung007.github.io/bring-your-own-ai-site/**

## Editing

This is a static site. To make changes, edit the HTML files directly and push
to the `main` branch. GitHub Pages will deploy automatically within ~60 seconds.

```bash
git add -A
git commit -m "Update privacy policy"
git push
```
